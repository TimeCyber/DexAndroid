# 大麦「选场次 → 选座 → 下单」流程接口文案

> 基于 Frida dump 字符串 + Request/Bean smali 整理，描述**业务链路**与关键接口字段。  
> 完整 POST 示例与请求/响应字段见下文「十三」及 `API文档.md` §10。  
> 主路径按「演出/演唱会类选座购票」整理；文末附「电影/淘票票」旁路对照。  
> 签名 / WUA / ecode 仍由 MTOP SDK 生成，本文不给出可复现算法。
---

## 一、整体流程（一句话）

先完成**登录并拿到会话/Token**，再选定项目与场次，拉**座位图/座位状态**并做选座预检，接着**算价 → 构建订单 → 创建订单 → 取支付参数 → 支付完成回调**；部分场景是「先下单后选座」。

```text
[登录/验证码/三方] → [Token/SSO/Cookie]
       → [项目/场次] → [座位图+状态] → [选座预检] → [算价]
       → [构建订单] → [创建订单] → [支付参数] → [支付完成]
```
---

## 二、阶段 1：进入项目 / 选择场次

用户输入或选定某个项目（project / item）后，客户端需要拿到项目详情、可售场次（perform）、票价档、区域等信息。

| 步骤 | 接口名 | 文案说明（职责推断） |
| --- | --- | --- |
| 1.1 项目详情 | `mtop.damai.item.detail.getdetail` | 拉取项目主详情（标题、场馆、票档、是否可选座等） |
| 1.1' 详情兼容 | `mtop.damai.item.detail.getdetail.1.0` | 详情接口版本变体 |
| 1.2 项目 ID 映射 | `mtop.damai.item.projectdetail.projectid.get` | 通过项目 ID 获取详情侧标识 |
| 1.3 老项目兼容 | `mtop.damai.item.oldproject.getitemid` | 老项目 ID 换新 itemId |
| 1.4 公告提示 | `mtop.damai.item.notice.query` | 项目购票须知 / 公告 |
| 1.5 区域信息 | `mtop.damai.wireless.project.getB2B2CAreaInfo` | 场馆区域 / B2B2C 区域结构 |
| 1.6 预选区域 | `mtop.damai.wireless.project.getpreareainfo` | 预售/预选区域信息 |
| 1.7 分区特殊规则 | `mtop.damai.maitix.division.getdisivionchildrenspecial` | Maitix 分区（含儿童票等特殊规则） |
| 1.8 日历场次 | `mtop.damai.wireless.search.performance.calendar.get` | 演出日历 / 场次列表（按日筛选） |
| 1.9 引导项目 | `mtop.damai.wireless.guide.base.project.get` | 引导页基础项目信息 |

**本阶段产出（逻辑上）：**  
`itemId / projectId`、`performId`（场次）、票价档 `priceId`、区域 `area`、是否支持选座标记。

**对应文案：**  
「打开项目页 → 展示场次列表 → 用户点选某一场次。」

## 三、阶段 2：弹出座次（座位图）

选定场次后，客户端请求座位静态/动态数据与售卖状态，渲染可选座位。

| 步骤 | 接口名 | 文案说明（职责推断） |
| --- | --- | --- |
| 2.1 选座参数 | `mtop.damai.wireless.seat.chooseSeatParam` | 进入选座页所需参数（场次、票档、限购等） |
| 2.2 动态信息 | `mtop.damai.wireless.seat.dynamicInfo` | 座位图动态层（缩放、热区、实时变化） |
| 2.3 场次座位状态 | `mtop.damai.wireless.seat.queryperformseatstatus` | 按场次查询座位可售/已售/锁定状态 |
| 2.4 票价颜色 | `mtop.damai.wireless.seat.querypricecolor` | 不同票价档在座位图上的颜色映射 |
| 2.5 选座预检 | `mtop.damai.wireless.seat.precheck` | 用户点座后校验：连座规则、限购、不可选原因 |

**本阶段产出：**  
座位列表/座位图、`seatId` 集合、票价档颜色、预检是否通过。

**对应文案：**  
「根据场次弹出座位图 → 标出可选/已售 → 用户点选座位 → 本地预检/服务端预检。」

## 八、主路径时序文案（推荐阅读版）

```text
① 用户输入/选定项目
   └─ mtop.damai.item.detail.getdetail
   └─（可选）performance.calendar.get / project.get*AreaInfo

② 用户选择场次 performId
   └─ mtop.damai.wireless.seat.chooseSeatParam
   └─ mtop.damai.wireless.seat.dynamicInfo
   └─ mtop.damai.wireless.seat.queryperformseatstatus
   └─ mtop.damai.wireless.seat.querypricecolor
   → 界面弹出座位图

③ 用户点选座位
   └─ mtop.damai.wireless.seat.precheck
   └─ mtop.damai.item.calcTicketPrice
   └─（可选）calcOrderPromotion

④ 进入确认订单
   └─ mtop.damai.trade.order.build
   └─（改信息）mtop.damai.trade.order.adjust

⑤ 提交下单（账号已登录态）
   └─ mtop.damai.trade.order.create
   └─（或）wireless.trade.common.order.create / spliceorder.create

⑥ 支付
   └─ paymentwaylist → getpayparam / orderpayparam
   └─ 渠道支付
   └─ paymentCompletion
```

③ 换票拿会话
   └─ applySsoToken / applySsoTokenV2
   └─ getWapLoginCookies（及可选 getAlipayCookies）

## 十一、关键核心接口速查（精简清单）

**登录 / Token（购票前置）：**

1. `mtop.taobao.mloginService.getLoginFlow` — 登录方式配置  
2. `mtop.mloginService.login` 或 `smsLogin` / `simLogin` / `oauthLogin` — 完成登录  
3. `mtop.mLoginTokenService.applySsoToken`（或 V2）— 申请 SSO Token  
4. `mtop.login.getWapLoginCookies` — 拉会话 Cookie  
5. `mtop.damai.mxm.user.token.get` — 大麦业务 Token  
6. `mtop.damai.mxm.user.accesstoken.get` — 大麦 AccessToken  

**必经（演出选座购票主链）：**

1. `mtop.damai.item.detail.getdetail` — 项目详情/场次入口  
2. `mtop.damai.wireless.seat.chooseSeatParam` — 选座页参数  
3. `mtop.damai.wireless.seat.queryperformseatstatus` — 座位状态  
4. `mtop.damai.wireless.seat.dynamicInfo` — 座位图动态数据  
5. `mtop.damai.wireless.seat.querypricecolor` — 票价颜色  
6. `mtop.damai.wireless.seat.precheck` — 选座校验  
7. `mtop.damai.item.calcTicketPrice` — 算价  
8. `mtop.damai.trade.order.build` — 构建确认单  
9. `mtop.damai.trade.order.adjust` — 调整确认单  
10. `mtop.damai.trade.order.create` — 创建订单  
11. `mtop.damai.wireless.order.getpayparam`（或 `orderpayparam`）— 支付参数  
12. `mtop.damai.wireless.order.paymentCompletion` — 支付完成  

**常见分支：**

- 拼场：`mtop.damai.spliceorder.create`  
- 先下单后选座：`remindchooseseat` → 选座 → `orderAfterChooseSeat`
